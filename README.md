# 酒店电视 · 云端资源库（自动更新）

这个仓库用来免费存放**影视仓配置**和**直播清单**，全部由 GitHub 免费服务器每天自动更新，**不需要你的电脑一直开着**。

## 仓库里的文件

| 文件 | 作用 |
|---|---|
| `tvbox.json` | 影视仓的配置（8 个点播采集站 + 1 个直播清单地址），**电视上填这个文件的地址** |
| `live_builder.js` | 直播源聚合脚本：每天从 5 个上游源拉取 → 清洗去重 → 探测 → 生成可用频道清单 |
| `live_all.m3u` | 生成的直播清单（**每天自动更新**，155 个左右可播频道） |
| `live_builder_report.txt` | 每次更新的运行报告（能看哪些台失效、耗时多少） |
| `.github/workflows/update-live.yml` | 定时任务：每天北京时间 06:30 自动跑一次聚合 |

## 电视上要填的地址

仓库建好后（用户名 `你的用户名`、仓库名 `hotel-tv`），影视仓「配置地址」填：

```
https://gh-proxy.com/https://raw.githubusercontent.com/huangshaoze37-tech/hotel-tv/main/tvbox.json
```

如果这个加速地址偶尔打不开，备选地址：

```
https://cdn.jsdelivr.net/gh/huangshaoze37-tech/hotel-tv@main/tvbox.json
```

## 直播源为什么每天更新

电视频道的免费直播源经常失效，所以每天 06:30 自动执行：

1. 从 5 个上游源拉取约 820 条频道
2. 同名频道合并（只留一个）、剔除 IPv6 和垃圾推广流
3. 逐个探测连通性，只保留能播的台（约 155 个）
4. 生成新的 `live_all.m3u` 并自动提交

电视打开直播时拉到的永远是最新清单，失效台第二天自动被踢掉。

## 手动触发更新

想立刻更新一次：仓库 **Actions** 页 → 左侧「每日自动更新直播源」→ 右侧 **Run workflow** → 绿色按钮。
